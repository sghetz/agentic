# Agentic

A personal macOS app that gives a Flutter developer an isolated software team of AI agents
(Orchestrator, Analyst, Health, Creative, Developer, Reviewer, Librarian), organized by
organization and project.

- Design: `docs/ARCHITECTURE.md`
- Agent roles: `docs/AGENTS.md`
- Roadmap: `docs/ROADMAP.md`
- Current phase: `docs/PHASE_0_SPEC.md`

Built in Dart (shared core + server) and Flutter (macOS app).
